# EvolveU Landing Page — Component Spec for Figma

## Frame setup
- Desktop frame: `1440 x 6200`.
- Container: `1120` centered.
- Vertical spacing between major sections: `64`.

## Core Components

### 1) Header / Navbar
- Logo (text lockup)
- Nav links (5)
- Primary CTA button
- Auto-layout: horizontal, space-between.

### 2) Hero Section
- Left: kicker, H1, body, 2 CTA buttons, proof list.
- Right: confidence snapshot card with progress bars.
- Auto-layout: 2-column desktop, 1-column mobile.

### 3) Pain Strip
- Dark navy band with 4 pain statements.
- Secondary supporting line centered below.

### 4) Course Grid (8 cards)
Card fields:
- Title
- One-line outcome
- Level badge
- CTA text link

### 5) 4-Step Method
Step card fields:
- Number badge
- Title
- Supporting text

### 6) USP Grid
- 4 cards: Hinglish Method, Mentor-Led, Structured Roadmaps, Transparent Pricing.

### 7) Pricing Cards
- 3-tier pricing table (A1 / B1 / C1)
- Middle card featured state with orange border and glow.

### 8) Assessment + Lead Form Split
- Left: info list.
- Right: form card with 4 fields and submit CTA.

### 9) Footer
- Brand blurb
- Quick links block
- Contact block

## Reusable UI Primitives
- Button / Primary
- Button / Secondary
- Card / Default
- Card / Featured
- Badge / Level
- Input / Text
- Input / Select
